# Multi-Agentic AI in Supply Chain Management

This project is a Multi-Agentic AI based Supply Chain Management system designed to improve decision-making, monitoring, and optimization in supply chain operations.

The system focuses on smart supply chain analysis using Python, machine learning, simulation, and dashboard-based visualization.

## Project Overview

Supply chain management involves multiple complex activities such as demand planning, inventory control, supplier coordination, production planning, and logistics monitoring.  
This project uses an agent-based approach to analyze different parts of the supply chain and support better decisions.

## Key Features

- Multi-agent based supply chain workflow
- Data preprocessing and analysis
- Machine learning model training
- Supply chain simulation
- Dashboard for visualization
- Dataset-based insights
- Paper and result analysis
